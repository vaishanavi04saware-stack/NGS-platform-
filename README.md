# Time to Answer

An interactive model of how long a 30x whole genome takes from library prep to variant calls on AXELIOS 1 versus a current high-output platform. Every time saving is tied to a specific product feature: right-sized runs, SBX run time, on-instrument analysis, and library prep.

Built as an independent concept from public sources (Roche's AXELIOS 1 spec sheet and launch release). Not affiliated with or endorsed by Roche. AXELIOS 1 is for research use only.

## Files
- `index.html`: page structure
- `style.css`: styles, including light and dark themes
- `app.js`: the model and interactions
